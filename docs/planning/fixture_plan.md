# 시험 지그 자동 설계와 사전 검증 프로그램 상세 기획

작성일 2026년 9월 28일 · 기획 버전 1.1 · 3D 프린팅 제작 과정 확장

## 1 목적과 개발 결정

소재 시편과 시험 조건을 입력하면 장비에서 시험할 수 있는지 먼저 판단하고, 지그 치수를 바꿔 해결할 수 있는 문제에는 수정 CAD를 만드는 프로그램을 개발한다. 지그 제작 후 발견하는 장착 불가, 하중 초과, 이동거리 부족, 지그 변형에 따른 측정 오류를 줄이는 것이 목적이다. 최종 산출물을 3D 프린팅 제작 파일, 금속 부품표, 조립·검사 정보까지 확장한다.

이번 개정에서는 자동 CAD 엔진을 CadQuery 중심으로 조정하고 FreeCAD는 기존 자산과 확인·편집 도구로 유지한다. 자연어 변경, 출력 재료·방향·레시피, 슬라이싱, 제작 후 확인은 20~27절에 상세히 정의한다.

| 결정 항목 | 채택안 | 이유 |
|---|---|---|
| 정적 시험 기준 장비 | ZwickRoell ProLine Z010 TH, 품목 059011, 10 kN | 인장·압축·굽힘에 대응하며 공개된 시험 공간·속도·연결부 사양이 구체적이다 |
| 반복 접힘의 동적 검토 장비 | Instron ElectroPuls E1000 | 동적 용량과 스트로크가 명시되어 있다. 접힘 지그 및 주파수별 운전 가능 여부는 추가 검증한다 |
| CAD 원본 | CadQuery 생성 Python과 parameters.json | 코드 기반 자동 생성·수정과 출력 파일 생성을 일관되게 관리한다 |
| CAD 확인과 기존 자산 | FreeCAD 및 선택적 FCStd 어댑터 | 형상 확인과 기존 파라메트릭 자산 편집을 지원한다 |
| 3D 프린팅 | PrusaSlicer CLI와 프린터별 프로파일 | 3MF와 실제 제작 조건을 묶어 슬라이싱과 제작 검사를 연결한다 |
| 사용자 프로그램 | Windows 우선 로컬 실행 프로그램, 브라우저 화면 | 회사 PC에서 자료를 외부로 보내지 않고 사용한다. 공개 사이트 배포는 필요 없다 |
| 3D 표시 | 실제 생성 CAD에서 만든 메시와 기구학 변환 | 형상과 결과가 연결되어야 하며, 단순 그림 위에 점만 표시하는 화면은 사용하지 않는다 |
| 첫 구현 순서 | 공통 엔진 → 굽힘 → 인장 → 압축 → 반복 접힘 → 챔버 공통 조건 | 네 시험을 모두 계획하되 검증하기 쉬운 순서로 개발한다 |
| 자동화의 범위 | 등록된 지그 계열 안에서 수정, 불가능하면 원인과 대안 제시 | 모든 CAD를 임의로 이해해 새 지그를 발명하는 기능은 범위에서 제외한다 |

이 문서는 개발 명세이며 완성 프로그램이나 제작 승인서가 아니다. 수치 시나리오는 검증 로직 개발용으로 정의한다. 제조사 사양, 프로젝트 가정, 계산값, 실측값을 데이터와 화면에서 구분한다.

성공 기준은 “CAD가 생성되었다”가 아니다. 입력 조건과 수정 이유를 추적할 수 있고, 알려진 실패 사례를 걸러내며, 계산과 형상 검증에 모두 통과한 설계안을 제시해야 한다.

## 2 장비 조사와 선정 근거

### 2.1 정적 장비 비교

| 항목 | Zwick ProLine Z010 TH | Instron 68TM-10 |
|---|---|---|
| 공칭 하중 | 10 kN | 10 kN |
| 대상 시험 | 인장·압축·굽힘 | 인장·압축·굽힘 |
| 이번 개발에서의 역할 | 기본 장비 프로파일 | 후속 교차 검증 프로파일 |
| 선정 판단 | 고신율 소재를 고려해 높은 시험 공간의 TH형을 선택 | 충분히 적합한 대안이나 1차 구현에서 두 제조사의 체결부를 동시에 구현하지 않는다 |

두 회사의 성능 우열을 단정한 선택이 아니다. 동일한 입력 구조로 다른 장비를 추가할 수 있도록 설계하고, 우선 하나의 정확한 모델과 형식에 집중한다. Z010이라는 이름만으로 ProLine과 AllroundLine의 사양을 혼용하지 않는다. [S1, S2]

### 2.2 기본 장비에 등록할 제조사 확인값

| 항목 | Zwick ProLine Z010 TH 값 | 해석 시 주의점 |
|---|---|---|
| 품목 번호 | 059011 | TN형 059010과 구별 |
| 최대 시험 하중 | 10,000 N | 장착한 로드셀·그립·어댑터는 별도 제한 |
| 시험 공간 높이 P | 1,450 mm | 부속품이 없는 공간. 시편의 허용 신장량이 아니다 |
| 크로스헤드 이동거리 | 1,380 mm | 조립 높이로 정해지는 가용 공간과 동시에 만족해야 한다 |
| 시험 공간 폭 | 440 mm | 챔버, 센서, 손잡이 등 국부 장애물은 별도 |
| 크로스헤드 시험 속도 | 0.0005~1,000 mm/min | 제조사 운전 조건을 함께 보관 |
| 복귀 속도 상한 | 1,500 mm/min | 시험 속도로 사용하지 않는다 |
| 연결 스터드 직경 | 20 mm | 끼워맞춤·횡핀·유효 길이·공차까지 확정된 것은 아니다 |
| 크로스헤드 부착 그립·공구 총질량 | 최대 20 kg | TH형의 공개 제한. 상부 부착품의 합산값에 적용 |

출처는 제조사 ProLine 표의 Z010 TH 열과 각주이다. 안전문 개방 시 속도 제한 등 운전 모드 조건도 프로파일에 보관한다. 제조사에서 설명하는 추가 하중 여유를 임의의 시험 용량 증대로 사용하지 않고 공칭 10 kN으로 계획한다. [S1]

정적 시험용 로드셀은 100 N, 1 kN, 10 kN의 세 용량군을 개발 목표로 둔다. 이는 선정 완료된 실제 재고 목록이 아니다. 제품 번호, 양방향 허용하중, 정확도 보증 범위, 교정 정보, 체결 호환성, 장착 질량을 확인한 부품만 실사용 후보에 올린다.

### 2.3 반복 접힘용 E1000 프로파일

| 항목 | 제조사 문서 확인값 |
|---|---|
| 동적 용량 | ±1,000 N |
| 정적 용량 | ±710 N |
| 총 스트로크 | 60 mm |
| 최대 개구 높이 | 액추에이터 중앙 위치에서 610 mm |
| 문서의 로드셀 | 베이스 장착 ±2 kN Dynacell |
| 하중 정확도 표현 | 지시값의 ±0.5% 또는 로드셀 용량의 ±0.005% 중 큰 값 |

출처 문서 표기는 ElectroPuls E1000_POD_EN_V9이다. 로드셀이 2 kN이어도 장비를 2 kN으로 사용하지 않는다. 동적 1 kN과 정적 710 N도 구분한다. [S3]

이 장비는 선형 액추에이터이므로 접힘에는 선형 변위를 회전으로 바꾸는 별도 기구가 필요하다. 60 mm 스트로크나 “100 Hz 이상”이라는 단일 문구로 특정 진폭·하중·질량에서의 연속 운전을 보증하지 않는다. 힘·진폭·주파수 운전 영역과 피로용 부속품의 정격을 확인하기 전에는 반복시험 적합 판정을 보류한다.

## 3 CAD와 라이선스 선택

**자동 형상 생성의 기본 엔진은 CadQuery로 정한다.** 3D 프린팅 제작까지 이어지는 코드 기반 자동화에 맞춰 1.0의 FreeCAD 중심 구성을 조정했다. Python 생성기와 parameters.json을 설계 원본으로 유지하고, STEP·STL·3MF·표시용 메시를 생성한다. FreeCAD는 형상 확인과 기존 FCStd 자산의 확인·편집 도구로 사용한다.

| 선택지 | 판단 |
|---|---|
| CadQuery | 기본 생성 엔진. Python 파라메트릭 모델·조립·STEP와 3MF 출력에 사용 |
| build123d | 대안 엔진. 동일 템플릿으로 실제 이점이 확인되는 경우 어댑터 교체 검토 |
| FreeCAD | 확인·편집 및 기존 FCStd 템플릿 지원. 기본 엔진과 부품 원본을 중복 관리하지 않음 |
| 상용 CAD | 기존 사내 자산을 연동하는 후속 선택지. 초기 실행에 필수로 두지 않음 |

CadQuery와 build123d는 Apache 2.0 기반이고 FreeCAD는 기업 사용이 가능한 오픈소스 CAD다. 실행 환경 배포 시 각 도구와 의존성의 라이선스 조건을 관리한다. “아무 제한도 없다”는 의미는 아니다. [S4~S6, S13]

파라미터의 원본은 parameters.json이고 CadQuery 생성기는 허용 범위와 설계 종속성을 구현한다. 사용자가 코드를 변경하면 새 템플릿 버전을 만들고 계산·형상·제조 검증을 다시 수행한다. 기존 FreeCAD 자산은 cad_backend=freecad인 별도 템플릿으로 지원할 수 있다.

STEP는 교환용 형상이며 원래의 피처 이력·수식·설계 의도를 일반적으로 보존하지 않는다. CadQuery STEP를 FreeCAD로 열면 형상을 확인할 수 있지만 CadQuery의 파라메트릭 이력이 복원되지는 않는다. 다른 CAD의 STEP만 받고 원본 파라미터를 자동 복원한다고 약속하지 않는다. [S12]

제조사 CAD에는 사용 조건이 있을 수 있으므로 배포 패키지에 무조건 포함하지 않는다. 공개 치수에서 만든 단순 공간 모델과 실제 체결부 형상을 구분한다. 도구 비교와 출력 파이프라인은 20~27절에서 구체화한다. [S2]

## 4 사용 흐름과 화면

사용자는 시험을 고르고 시편 정보를 넣은 뒤, 보유 장비 구성을 선택한다. 프로그램은 현재 지그의 문제를 보여주고 수정안을 계산한다. 사용자가 수정안을 선택하면 같은 검증을 다시 수행한 CAD와 보고서를 저장한다. 제작 화면에서 출력 방향·프린터·재료·부품표를 확인하고 슬라이싱과 제작 후 검사로 이어간다.

| 화면 | 입력과 기능 | 반드시 보일 결과 |
|---|---|---|
| 시험 만들기 | 인장·압축·3점 굽힘·반복 접힘 선택, 프로젝트 불러오기 | 시험 목적, 비교 기준, 사용하는 단위 |
| 시편과 조건 | 치수·물성 범위, 온도, 속도, 목표 변형·횟수 | 필수 누락값, 예상 범위, 출처 구분 |
| 장비와 지그 | 본체 → 로드셀 → 어댑터 → 지그의 실제 조립 구성 | 전체 제한을 결정하는 부품, 조립 높이·질량 |
| 검증 결과 | 계산 결과, 제약별 판정, 근거 펼치기 | 현재값 / 요구값 / 허용값 / 차이 / 해결 방법 |
| 수정안 비교 | 원안과 후보를 나란히 확인 | 변경 치수, 교체 부품, 남은 문제, 신규 제작 부품 |
| 3D 동작 확인 | 회전·확대·분해, 변위 또는 각도 슬라이더 | 실제 CAD 부품, 이동 궤적, 충돌 위치, 센서 위치 |
| 결과 내보내기 | 원본 CAD·STEP·검토 보고서·입력 묶음 | 버전과 검증 범위, 누락 항목 |

기본 화면에서는 시험에 필요한 항목만 보인다. 물성 근거, 안전 여유, 접촉 가정, 세부 공차는 확장 영역에서 보여준다. 값 하나를 바꾸면 이전 결과에는 “입력 변경으로 재검증 필요” 표시를 붙인다.

3D 애니메이션은 기구학 표시인지, 해석 결과인지 명확히 표시한다. 솔버 없이 시편을 시각적으로 휘게 만든 그림을 응력 해석 결과처럼 표시하지 않는다. 지그·시편·로드셀은 별도 선택 가능 객체이며 객체를 누르면 연결된 검증 항목이 열린다.

## 5 공통 판정 규칙

### 5.1 판정 상태

| 상태 | 정의 | 예시 |
|---|---|---|
| PASS 조건 내 적합 | 해당 검증에 필요한 데이터가 있고 기준을 만족 | 확인된 최대 하중 이내 |
| FAIL 부적합 | 확인된 한계를 위반 | 1 kN 로드셀에 설계 하중 2.5 kN |
| UNKNOWN 판정 보류 | 필수 사양·모델·실측 근거가 없음 | 체결 핀 허용하중 미등록 |
| WARNING 확인 권고 | 판정은 가능하지만 여유나 모델 적용성이 제한적 | 허용치에 가까운 공간 여유 |

FAIL이 하나라도 있으면 현재 구성은 부적합이다. FAIL이 없어도 필수 UNKNOWN이 있으면 종합 적합을 주지 않는다. 계산 검증, 형상 검증, 구조 검증, 실물 검증은 별도 상태로 저장한다. 시뮬레이션 예제의 PASS는 실제 장비 적합과 다르다.

### 5.2 모든 시험의 필수 검사

1. 단위와 입력 유효성: mm와 m, N와 kN, Pa와 MPa, %와 비율 혼동을 차단한다. 범위 역전·음수 치수·NaN도 거부한다.
2. 적용 가능성: 선택한 계산식이 재료·변형 범위·시험 방법에 적합한지 먼저 판단한다.
3. 하중 경로: 본체, 로드셀, 그립, 핀, 볼트, 어댑터, 지그의 방향별 허용치를 각각 비교한다. 자중과 편심, 동적 관성은 해당 부품에 실제로 작용하는 만큼 포함한다.
4. 공간과 이동: 초기 조립과 시험 종료 상태뿐 아니라 중간 경로에서 공간, 이동거리, 센서·챔버 간섭을 검사한다.
5. 측정 품질: 관심 구간의 하중·변위가 센서 보증 범위에 있는지, 지그·프레임 변형이 측정에 섞이는지 검사한다.
6. 형상과 구조: CAD 재생성, 솔리드 유효성, 실제 반영 치수, 연결 관계, 강도·강성 검증 범위를 확인한다.
7. 제작 가능성: 선택한 가공 방식의 최소 두께, 구멍 간격, 공구 접근, 조립 순서, 표준 부품 크기를 확인한다.

### 5.3 변경 권한

자동 변경 가능: 등록 범위 안의 지그 판 두께, 베이스 길이, 지지대 위치, 물림 길이, 교체형 인서트, 어댑터 길이, 재고 부품 선택.

고정 조건: 시험 규격, 목표 접힘 반경·각도·횟수, 시편 단면·적층·길이, 비교 시험의 경계조건. 고정 조건을 바꿔야만 해결되면 별도 대안으로 표시하고 원 시험의 성공으로 간주하지 않는다.

개발 예제의 하중 설계 계수는 1.25로 둔다. 이것은 규격의 보편적 안전율이 아니라 계획용 여유이다. 재료 물성의 상한과 별도로 적용하며, 장비 제조사가 지정한 한계는 늘리지 않는다. 부품 강도에 적용할 안전율·피로 계수는 검토 정책에서 따로 정한다.

## 6 인장시험 시나리오

### T1 강한 플라스틱으로 바뀌어 로드셀과 연결부가 부족한 경우

개발 입력: 시험부 폭 10 mm, 두께 2 mm, 예상 공칭 인장강도 60~100 MPa. 예상 최대 하중 범위는 1.2~2.0 kN이고 설계 하중은 상한의 1.25배인 2.5 kN이다.

현재 구성은 1 kN 로드셀, 2 kN 연결 어댑터를 가정한다. 10 kN 본체가 있어도 두 부품 모두 부적합이다. 프로그램은 확인된 호환 부품 중 적합한 로드셀·어댑터를 먼저 찾고, 연결부 두께·핀 지름 변경이 허용된 템플릿에서는 구조 검토가 가능한 후보를 만든다. 센서 용량은 CAD 치수 변경으로 해결하지 않는다.

출력 예: “로드셀 1,000 N < 설계 하중 2,500 N. 어댑터 2,000 N < 2,500 N. 본체는 용량 이내. 두 부품 교체 후 체결·공간 재검증 필요.”

인장 최대 하중은 공칭강도 × 초기 단면적으로 산정한다. 항복강도만 입력되면 파단까지의 최대 하중을 알 수 없으므로 파단시험 적합을 확정하지 않는다. 진응력은 초기 면적과 직접 곱하지 않는다.

### T2 고무가 길게 늘어나 종료 전에 공간이 부족한 경우

개발 입력: 평행부의 균일 스트립, 폭 4 mm, 두께 2 mm, 초기 그립 간 자유 길이 100 mm, 목표 공칭 신장률 500%, 예상 강도 상한 15 MPa. 시편 신장량은 500 mm, 시편 힘은 약 120 N, 설계 하중은 150 N이다.

개발 조립 가정: 시편을 제외한 로드셀·그립·긴 연장봉 합산 높이 800 mm, 끝단 여유 100 mm. Z010 TH의 1,450 mm 공간에서 쓸 수 있는 추가 신장량은 450 mm이므로 50 mm 부족하다. 긴 연장봉을 줄여 합산 높이 650 mm로 만들면 가용 신장량은 600 mm가 된다. 크로스헤드 위치와 센서 추적 범위도 별도 확인한다.

자동 변경: 연장봉·어댑터 길이와 설치 높이. 변경 금지: 물성시험의 목표 신장률이나 시편 규정 치수. 덤벨 시편에서는 표점 길이 × 신장률을 그립 이동량과 동일하게 쓰지 않고, 어깨부 변형을 포함한 추정 또는 실측 변위 이력을 사용한다.

### T3 얇은 필름의 미끄러짐과 저하중 측정 문제

개발 입력: 폭 10 mm, 두께 0.05 mm, 강도 상한 80 MPa. 예상 최대 힘 40 N, 설계 하중 50 N이다. 파단 하중만 보면 큰 로드셀에도 충분하지만, 탄성구간의 관심 하중이 0.1 N이면 보증 범위가 이를 포함해야 한다.

로드셀은 용량보다 교정·정확도 범위를 먼저 비교한다. 예제용 큰 로드셀의 보증 하한 1 N, 작은 로드셀의 보증 하한 0.02 N을 별도 가상 데이터로 둔다. 이 값은 실제 Zwick 제품 사양이 아니다.

그립은 양면 접촉압, 마찰계수의 범위, 물림 길이, 표면 종류를 입력한다. 단순 마찰 모델은 미끄러짐의 1차 평가에만 쓰며, 패드 압축·필름 찢어짐의 한계가 없으면 UNKNOWN으로 둔다. 자동 변경은 물림 길이·패드 두께·모서리 반경이며, 최종 확인은 소량 시편의 미끄러짐·물림부 파손 시험이다. ISO 527-3과 ASTM D882는 동등한 규칙 묶음으로 취급하지 않는다. [S7]

## 7 압축시험 시나리오

### C1 발포재 크기가 커져 하중과 압축판 크기가 달라진 경우

개발 입력: 50 × 50 × 25 mm 발포재, 목표 압축률 50%, 해당 변형에서 공칭 압축응력 상한 0.2 MPa. 예상 힘은 500 N, 설계 하중 625 N, 시편 압축 변위는 12.5 mm이다.

자동 변경: 평판 폭·길이·두께, 센서 브래킷 높이. 70 × 70 mm 평판을 첫 후보로 두되, 이것은 시험 규격을 확정한 값이 아니다. 시편의 횡방향 팽창과 끝단 마찰 조건을 확인한다. 반력 지지 위치와 판 휨을 검토하고, 압축 종료 전에 지그가 닿는지 검사한다.

발포재에 선형 탄성률 하나만 주고 50% 압축력을 계산하지 않는다. 압축 곡선이나 목표 압축률에서의 응력 범위가 필요하다. 발포재와 단단한 플라스틱은 다른 시험법 프로파일을 사용한다. [S8]

### C2 단단한 시편보다 지그 변형이 커서 탄성률이 틀어지는 경우

개발 입력: 단면 10 × 10 mm, 높이 10 mm, 탄성률 3,000 MPa, 선형 범위 내 목표 변형률 2%라는 가정. 힘은 6,000 N, 시편 변형은 0.2 mm, 설계 하중은 7,500 N이다.

지그 축방향 강성을 20,000 N/mm로 가정하면 지그만 0.3 mm 변형한다. 크로스헤드에서 0.5 mm를 모두 시편 변형으로 해석하면 겉보기 탄성률은 1,200 MPa가 된다. 이 계산은 프레임·로드셀의 추가 변형을 제외한 설명 예제다.

프로그램은 지그 강성 증대안과 시편 직접 변위 측정안을 나란히 보여준다. 지그 변형을 시편 변형의 5% 이내로 제한한다는 개발 목표라면 필요한 지그 강성은 600,000 N/mm 이상이다. 판 두께만 조금 늘려 해결된다고 처리하지 않는다. 직접 변위계를 쓰더라도 평행도·접촉면·좌굴과 하중 전달 문제는 별도 검토한다. [S9]

### C3 지그를 아무리 바꿔도 본체 용량이 부족한 경우

개발 입력: 단면 20 × 20 mm, 목표 공칭 압축응력 40 MPa. 힘 16 kN, 설계 하중 20 kN으로 10 kN 본체를 초과한다.

결과는 “현 장비에서 불가”다. 시편 면적을 몰래 줄이지 않는다. 더 큰 장비로 전환하거나, 시험법이 허용하는 시편 변경을 별도 검토안으로 제시한다. 이 실패 시나리오는 프로그램이 무조건 CAD 수정안을 내지 않는지 확인하는 핵심 테스트다.

## 8 3점 굽힘 시나리오

### B1 기본 플라스틱 시편의 굽힘 지그 생성

개발 입력: 폭 10 mm, 두께 4 mm, 길이 80 mm, 지지 간격 64 mm, 탄성률 2,000 MPa. 소변형 선형보 가정에서 표면 변형률 0.5%에 대응하는 힘은 약 16.667 N, 중앙 처짐은 약 0.8533 mm이다.

공칭 굽힘강도 80 MPa에서의 하중 환산값은 약 133.333 N이고 1.25배 설계 하중은 약 166.667 N이다. 선형 탄성률로 파단 처짐까지 외삽하지 않는다. 목표 처짐은 시험 방법 또는 실제 곡선에서 별도로 입력한다.

지그 구성: 베이스, 좌우 위치 조절 지지대, 교체형 지지 롤러, 중앙 압자, 정렬 스토퍼, 시편 아래의 독립 변위 센서 브래킷. 지지대는 중심을 유지하며 대칭 이동한다. 롤러·압자 반경은 승인된 시험법 프로파일에서 정하고, 하중을 낮추기 위한 자유 최적화 변수로 쓰지 않는다. [S10]

### B2 시편 두께 증가로 지지 간격이 기존 조절 범위를 벗어난 경우

개발 입력: 폭 10 mm, 두께 8 mm, 길이 200 mm. 개발 규칙으로 지지 간격/두께 비 16을 지정하면 지지 간격 128 mm가 필요하다. 이 비율은 모든 재료·규격에 공통 적용하지 않는다.

기존 지그의 최대 지지 간격을 100 mm로 가정한다. 프로그램은 128 mm까지 지지대를 이동시키는 동시에 베이스 길이·가이드 유효 길이·볼트 위치를 바꾼다. 220 mm 베이스와 최대 간격 160 mm를 초기 후보로 두고, 실제 CAD와 구조 검증 후 채택한다.

동일 0.5% 표면 변형률에서 약 33.333 N, 처짐 1.7067 mm이며, 굽힘강도 80 MPa 기준 하중은 약 266.667 N이다. 단순히 “두께 두 배이므로 힘 여덟 배”로 계산하지 않는다. 지지 간격과 목표 변형 조건도 동시에 달라졌기 때문이다.

시편 길이를 80 mm로 유지한 입력에서는 128 mm 지지 간격을 수용할 수 없다. 지그 확대만으로 해결되었다고 판정하지 않는다.

### B3 적층 복합재와 전단 변형이 중요한 경우

입력에 적층 방향, 각 층 두께, 방향별 탄성률과 전단 계수, 계면 조건을 추가한다. 등방성 탄성률 하나와 두께만으로 모든 적층재를 판정하지 않는다. 필요하면 적층판 강성 또는 전단 변형을 포함한 보 모델, 접촉 해석으로 넘긴다.

초기 버전은 CAD 형상·공간·입력 하중 기반 용량 검사를 지원한다. 신뢰할 수 있는 하중 곡선이나 해석 결과가 없으면 하중 예측과 박리·파손 판단은 UNKNOWN으로 둔다. 적층 손상 수명 예측을 지그 자동 치수화 기능과 혼동하지 않는다.

## 9 반복 접힘 시나리오

### F1 접힘 반경은 같아도 두꺼운 소재에서 요구 변형이 증가하는 경우

단층 필름의 개발 입력: 두께 0.2 mm, 폭 20 mm, 안쪽 반경 2 mm. 중립면이 두께 중앙에 있고 원호로 순수 굽힘한다는 가정에서 중립면 반경은 2.1 mm, 표면 변형률은 약 4.762%다.

반경을 5 mm로 바꾸면 약 1.961%로 낮아지지만, 원 시험의 목표 반경이 2 mm이면 이를 자동 해결안으로 적용하지 않는다. 프로그램은 “시편 요구 변형이 지정한 재료 모델의 검증 범위를 초과한다”를 표시하고 하중 예측의 신뢰도를 낮춘다.

기구 구성: 좌우 회전 클램프, 반경 인서트, 시편 길이 변화를 흡수하는 슬라이드 또는 부동 그립, 대칭 구동부, 회전각 센서, 가이드 베어링. 각도만 맞고 시편에 불필요한 인장력이 생기는 구조를 허용하지 않는다. 시편 중심선 궤적·그립 사이 길이·접촉점 이동을 함께 검사한다.

적층재에서는 중립면 위치, 층간 미끄러짐과 박리를 고려해야 한다. 단층 계산을 CFRP와 슬립 시트 적층재의 손상 판단에 그대로 쓰지 않는다.

### F2 15만 회 반복 접힘의 속도와 관성 검토

개발 목표: 평탄 상태 0°에서 접힘 180°까지 왕복, 초당 2회, 총 150,000회. 정지 시간을 제외한 순수 운전 시간은 약 20.833시간이다.

기구학 검증용 모델은 피치 반경 12 mm인 랙·피니언과 좌우 반대 회전 기어를 사용한다. 각 클램프가 전체 접힘각의 절반씩 회전한다고 가정하면 전체 각도 θ에 대해 랙 이동 x = r × θ / 2가 된다. θ는 라디안이다. 전체 선형 스트로크는 약 18.850 mm다. 실제 베어링·백래시·가이드·그립 궤적을 설계하기 전의 이상 기구학 모델이다.

2 Hz 정현 운동에서 선형 진폭은 약 9.425 mm, 최대 속도는 118.435 mm/s, 즉 7,106.1 mm/min이다. 이는 Z010 TH의 시험 속도 1,000 mm/min보다 크다. 정적 장비에 지그만 달아 목표 시험이 된다고 판정해서는 안 된다.

E1000의 60 mm 총 스트로크 안에는 들어가지만 이것만으로 적합은 아니다. 최대 가속도 약 1.488 m/s², 움직이는 질량 0.5 kg을 가정한 선형 관성력 약 0.744 N 외에 회전 관성·마찰·시편 저항·부품 자중을 포함해야 한다. 시편이 약하면 관성력도 측정값을 크게 오염시킬 수 있다.

일반 기구의 액추에이터 힘은 순간 기구비에 의해 달라진다. 각도에 대한 변위 미분이 0에 가까워지는 사점, 끝단 충돌, 허용 편심, 베어링 수명, 풀림, 피로를 검사한다. 본 예의 이상 랙 구동은 일정 기구비를 가지지만 시편 굽힘 반경 유지와 길이 보상까지 자동 보장하지 않는다.

### F3 접힘 힘이 작아 센서의 오차가 지배하는 경우

E1000 문서의 2 kN 로드셀과 정확도 식을 적용하면 절대오차 하한은 0.1 N이다. 시편 신호가 2 N인 예에서는 지시값 0.5%인 0.01 N보다 0.1 N이 크므로 상대오차는 5%다. 목표 정확도가 1%라면 이 구성의 측정 품질은 부적합이다. [S3]

대안은 제조사가 허용한 더 적합한 측정 구성, 별도 센서, 기구비 변경이다. 기구비를 바꾸면 힘뿐 아니라 스트로크·속도·관성·백래시도 다시 검토한다. 저하중 접힘을 위해 동적 장비 이름만 바꾸면 해결된다고 처리하지 않는다.

초기 반복 접힘 기능의 완료 범위는 기구학·공간·하중 경로·측정 범위 검토와 CAD 생성이다. 15만 회에서의 시편 균열·계면 박리 수명은 별도 재료·피로 모델 및 실험 검증이 필요한 후속 기능이다.

## 10 챔버와 환경 조건 공통 시나리오

### H1 상온에서 맞는 지그가 온도 챔버에서 충돌하는 경우

개발 가정은 유효 내부 폭 200 mm, 깊이 200 mm, 높이 300 mm인 가상 챔버다. 제조사 제품의 실제 사양으로 등록하지 않는다. 폭 210 mm 지그는 정지 상태부터 들어가지 않는다. 폭을 줄였어도 회전하는 손잡이, 이동하는 압자, 센서 암, 케이블이 중간 위치에서 충돌할 수 있다.

일정 여유를 가진 챔버 공간 모델과 지그의 운동 궤적을 비교한다. 고온·저온에서는 지그 재료 강도, 치수 변화, 윤활·패드·접착제, 센서 정격, 열전달과 온도 안정화를 추가 검토한다. 온도별 물성 정보가 없으면 상온 값을 자동 적용하지 않는다.

E1000에 일반적인 챔버를 조합할 수 있다고 가정하지 않는다. 제조사의 ElectroPuls 액세서리 안내에는 E1000이 제외되는 챔버도 있으므로 장비별 호환 품목을 확인해야 한다. [S11]

## 11 계산 모델과 적용 한계

기본 내부 단위는 N, mm, s, MPa, rad, kg로 통일한다. 질량에서 관성력을 구할 때 가속도 mm/s²를 m/s²로 변환한다. CAD 길이 단위는 mm다. 외부 입력은 단위를 명시한 뒤 변환한다.

| 계산 | 식 또는 처리 | 적용 한계 |
|---|---|---|
| 인장 최대 하중 | F = 공칭강도 × 초기 단면적 | 강도 범위·온도·속도 조건 필요 |
| 균일 스트립 신장 | ΔL = 초기 자유 길이 × 공칭 신장률 | 덤벨·그립 미끄러짐에는 직접 적용 금지 |
| 압축 하중 | F = 공칭 압축응력 × 초기 단면적 | 진응력 또는 횡팽창이 큰 경우 면적 정의를 구분 |
| 선형 압축 | F = E × A × δ / L | 작은 변형의 검증된 선형 구간만 |
| 3점 굽힘 응력 | σ = 3 F L / (2 b h²) | 단순 지지, 중앙 하중, 적합한 보 모델 |
| 3점 굽힘 처짐 | δ = F L³ / (4 E b h³) | 소변형·선형 탄성·전단 영향이 작은 구간 |
| 굽힘 표면 변형률 | ε = 6 h δ / L² | 같은 보 모델의 적용 조건 |
| 단층 순수 굽힘 | ε ≈ h / (2 R중립면) | 중립면·막변형·층간 미끄러짐 가정 필요 |
| 직렬 탄성 컴플라이언스 | C전체 = C시편 + C지그 + C로드셀 + C프레임 | 접촉·유격·미끄러짐은 별도 |
| 정현 운동 | vmax = 2πfA, amax = (2πf)²A | A는 편진폭. 왕복 스트로크와 구분 |
| 운전 시간 | 시간 = 사이클 수 / 주파수 | 휴지·점검·가감속 시간 별도 |
| 일반 기구 힘 | F = Mθ / (dx/dθ) | θ에 대응하는 일반화 모멘트 정의, 마찰·관성 추가 |

표의 식은 개발 계산 모델의 정의다. 시험 규격 전체를 구현한 것으로 취급하지 않는다. 규격 프로파일에는 문서명·판·적용 소재·시편 조건·허용 변경·검토자를 저장한다. 공개 제조사 해설로 후보 규칙을 만들 수 있지만, 규격 적합 표시를 제공하기 전에는 실제 적용 판의 정식 문서와 대조한다.

체결부 강도는 단면적만으로 승인하지 않는다. 핀 전단·베어링 압력·순단면·볼트 인장과 전단·예압·굽힘·응력집중을 필요한 수준으로 평가한다. 적용할 구조 모델이 등록되지 않은 지그는 CAD만 생성 가능하고 구조 검증은 UNKNOWN이다.

## 12 자동 수정과 후보 선택 알고리즘

1. 입력, 장비 구성, 규칙, CAD 템플릿 버전을 고정하고 해시를 만든다.
2. 현재 구성을 평가한다. 누락 필수 데이터와 확정 위반을 분리한다.
3. 위반마다 수정 가능한 변수를 연결한다. 하중 초과를 베이스 길이 변경으로 해결하는 식의 무관한 조정을 금지한다.
4. 기존 부품의 위치 조절 → 재고 부품 교체 → 신규 부품 최소 제작 순서로 후보를 만든다.
5. 물성의 상·하한과 치수 공차를 사용해 후보를 검사한다. 입력이 충분하지 않으면 “강건한 설계”라고 표현하지 않는다.
6. 계산식으로 빠르게 탈락시킨 후 남은 후보만 CAD로 생성한다.
7. CAD 유효성·실제 치수·전 경로 간섭·질량·연결을 검사한다. 필요한 구조 검증을 수행하거나 UNKNOWN으로 남긴다.
8. 모든 고정 조건을 유지한 후보 중 신규 제작 부품 수, 변경량, 공간 여유, 검증된 성능으로 순위를 정한다. 미확인 가공비를 숫자로 만들어 비용 최적화했다고 표시하지 않는다.
9. 해결 후보가 없으면 위반 조건과 변경 가능한 대안을 출력한다. 탐색 횟수 소진과 물리적 불가능을 구분한다.

초기에는 등록된 이산 부품과 제한된 치수 범위를 열거하는 결정적 알고리즘을 사용한다. 근거가 약한 다목적 최적화와 LLM 판단을 핵심 판정에 넣지 않는다. 같은 입력과 같은 버전이면 수치와 판정이 재현되어야 한다.

## 13 CAD 템플릿 상세

| 템플릿 | 부품 구성 | 주요 자동 변경값 | 고정 또는 제한값 |
|---|---|---|---|
| T 인장 | 상하 그립, 인서트, 어댑터, 연결 핀, 시편 | 물림 길이, 패드 두께, 어댑터 길이 | 시험부 치수, 하중축, 제조사 체결 규격 |
| C 압축 | 상하 평판, 지지 블록, 정렬부, 변위계 브래킷 | 평판 폭·길이·두께, 브래킷 높이 | 시편 단면, 목표 압축량, 평행도 요구 |
| B 굽힘 | 베이스, 지지대, 롤러, 중앙 압자, 위치 스토퍼 | 지지 간격, 베이스 길이·두께, 볼트 위치 | 시험법의 롤러 반경, 압자 중심, 규정 지지 간격 |
| F 접힘 | 좌우 클램프, 기어·랙, 회전축, 인서트, 슬라이드, 센서 | 클램프 폭, 부동 길이, 가이드 길이, 축 지지 간격 | 목표 반경·각도, 하중축, 규정 기구 운동 |

모든 치수에 이름, 단위, 최소·최대·증분, 역할, 종속식, 고정 여부, 검증 방법을 부여한다. 형상 참조는 임의 Face1·Edge2 번호에 의존하지 않고 기준 좌표계·기준면·이름 있는 객체를 사용한다.

연결부에는 제조사 도면의 실제 길이·공차·핀 위치를 등록해야 한다. 직경 20 mm만 확인된 상태에서는 원통형 참고 모델을 만들 수 있지만 실제 제작 가능한 어댑터로 내보내지 않는다. CAD의 마지막 정상 형상을 보존하고 재생성 실패 파일을 정상 결과처럼 표시하지 않는다.

기본 운동 검증은 일정 간격의 위치를 확인하고 간격이 좁아지는 구간을 적응적으로 세분한다. 단순 위치 샘플만으로 모든 간섭이 없다고 보증하지 않는다. 중요 구간에는 보수적 swept envelope 또는 연속 충돌 검사를 사용하고, 미검증 구간을 기록한다. 변형된 시편과 케이블의 공간은 별도 모델로 검사한다.

수치값에는 value 또는 lower/upper, unit, provenance, evidence_id를 붙인다. provenance는 manufacturer_document, measured, project_assumption, derived 중 하나다. null을 0으로 해석하지 않는다. 자료 미등록과 한계 없음은 서로 다른 값이다.

로드셀 측정 오차는 단일 “정확도 %”로 저장하지 않는다. 판독값 비율, 용량 비율, 절대 오차, 보증 하한, 방향, 교정일, 동적 적용성을 표현한다. 정적·동적 용량도 따로 저장한다.

프로그램 모듈:

- domain: 단위, 데이터 검증, 물성·장비·부품 모델.
- calculations: 인장·압축·굽힘·접힘 계산과 적용 범위 판정.
- rules: 규칙 실행, 상태 통합, 근거와 개선안 생성.
- design: 후보 생성, 고정 조건 보존, 후보 순위.
- cad_worker: CadQuery 작업 프로세스에서 템플릿 재생성·측정·내보내기. 기존 FCStd용 FreeCAD 어댑터는 선택적으로 연결한다.
- motion: 위치와 각도 이력, 간섭·공간 검증.
- analysis_adapter: 구조 해석 요청·결과 수신. 미실행 결과를 PASS로 바꾸지 않는다.
- report: 입력·변경·판정·근거를 묶은 HTML 및 JSON 보고서.
- api와 ui: 작업 생성, 진행 상태, 3D 표시, 비교, 내보내기.

## 15 기술 구성과 실행 방식

Python 계산 엔진과 FastAPI 로컬 서버, React·TypeScript 화면, Three.js 기반 3D 뷰어, SQLite 메타데이터, 파일 기반 프로젝트 폴더를 사용한다. CadQuery 작업자와 서버 Python 환경을 분리해 라이브러리 충돌을 줄인다. 선택적 FreeCAD와 PrusaSlicer는 검증된 실행 파일 경로를 지정한다. 제작 기능의 도구·데이터·인터페이스는 20~27절을 따른다.

Windows 실행 파일 또는 시작 스크립트 하나로 서버와 화면을 연다. 서버는 기본적으로 localhost에만 바인딩한다. 모든 정적 자산을 로컬에 포함하고 외부 CDN·클라우드·LLM 호출 없이 작동하도록 한다. Linux에서도 계산과 CAD 회귀 검증이 가능하도록 경로와 프로세스 실행을 추상화한다.

버전은 개발 착수 시 실제 설치·기동·CAD 재생성 테스트를 통과한 조합으로 고정한다. 최신 버전을 자동 추종하지 않는다. GPU는 필수 조건이 아니며, 초기 형상 규모는 일반 PC의 CPU로 처리 가능한 지그 조립으로 제한한다.

이번 제품은 장비 선정과 지그 설계 검토 도구다. Instron이나 Zwick 시험기를 직접 구동하지 않는다. 장비 제어가 필요해지면 해당 제조사의 허용 인터페이스와 제어·정지 조건을 별도 개발 범위로 정의한다. CAD가 무료여도 제조사의 시험 제어 소프트웨어 사용권이 없어지는 것은 아니다.

## 16 테스트 계획과 완료 기준

### 16.1 계산과 규칙 테스트

아래는 구현 시 필수 수용시험이다. 첨부 acceptance_tests.csv에서 ID별 입력 조건, 기대 결과, 검증 방식을 확인한다.

| 구분 | 핵심 테스트 |
|---|---|
| 수치 정답 | T1 하중, T2 신장·공간, C1 압축, C2 컴플라이언스, B1/B2 보 계산, F2 기구학 |
| 단위 | mm↔m, N↔kN, MPa↔Pa, %↔비율, deg↔rad, mm/s²↔m/s² |
| 한계 | 정격 직전·정격과 동일·정격 초과, 두께 최소·최대, 속도·공간 경계 |
| 물리 | 항복값만으로 파단 하중 산정 금지, 발포재 E로 대변형 외삽 금지, 적층재 등방성 치환 금지 |
| 데이터 | 단위 누락, NaN, 음수 치수, 범위 역전, 필수값 null, 실물 미확인 |
| 의도 보존 | 시편 치수와 접힘 반경을 자동으로 바꿔 통과시키지 않음 |
| 장비 | 본체·로드셀·그립의 최소 허용치, 정적/동적 정격 분리, 속도와 복귀 속도 구분 |
| 재현 | 같은 입력·버전에 동일 수치·판정, 변경 후 이전 결과 무효화 |

### 16.2 CAD와 화면 테스트

각 템플릿은 최소·대표·최대 치수와 실패 입력을 포함해 검증한다. 파라미터를 바꾼 뒤 실제 측정한 간격·두께가 목표와 맞아야 한다. 검사용 길이 허용오차 0.01 mm는 소프트웨어 형상 회귀 기준이며 가공 공차를 의미하지 않는다.

STEP 재불러오기 후 솔리드 수·기준 치수·체적을 비교한다. 부품이 빠진 내보내기, CAD 재생성 실패, 작업 취소, 중간 충돌, 표시용 메시와 CAD 버전 불일치를 검출한다. 화면에서 원안과 수정안의 변경 치수를 선택하면 해당 부품이 강조되어야 한다.

### 16.3 구조와 실물 검증

단순 지그는 독립 손계산이나 검증된 구조 해석과 비교한다. 접촉·미끄러짐·좌굴·복합재 손상처럼 입력 의존성이 큰 항목은 시험으로 보완한다. 실제 장착 시험에서는 치수, 초기 위치, 무시편 운동, 알려진 하중·변위, 지그 컴플라이언스 순서로 확인한다.

반복 접힘은 저속 궤적과 힘을 먼저 측정하고, 목표 속도에서 관성·발열·풀림·센서 신호를 확인한 뒤 단계적으로 반복 횟수를 늘린다. 짧은 무부하 반복 성공을 15만 회 수명 검증으로 표시하지 않는다.

### 16.4 완료 판정

- 계획된 모든 규칙·경계 수용시험이 통과하고, 설명 가능한 정답과 비교되어야 한다.
- 네 시험의 대표 CAD가 생성되며, 적합·부적합·판정 보류 사례가 모두 재현되어야 한다.
- 알려진 부적합 사례가 적합으로 나오는 오판이 없어야 한다.
- 모든 PASS에는 적용한 규칙·입력·근거·버전이 있어야 한다.
- 실제 제작용 출력은 필수 인터페이스와 구조 검증이 완료된 경우에만 허용한다. 미확인 상태에서도 검토용 CAD는 표시를 붙여 출력할 수 있다.
- 현장 실측이 없으면 “소프트웨어 기능 검증 완료”까지만 표시한다. “실물 시험 적합 확인”과 구분한다.

## 18 개발 인계 지시

개발자는 이 문서, equipment_profiles.json, scenario_inputs.json, acceptance_tests.csv와 제조 확장 파일 manufacturing_profiles.json, printing_scenarios.json, print_acceptance_tests.csv를 읽고 구현을 시작한다. 먼저 계산과 판정 엔진을 만든 다음 실제 CadQuery 재생성과 화면을 연결한다. 예제 데이터에 맞춰 결과를 하드코딩하지 않는다.

이번 기획 패키지의 verify_planning_examples.py는 문서에 등장하는 계산 예제를 검산하는 보조 코드다. 이것이 통과해도 제품 계산 엔진, CAD 생성, 간섭 검사, 구조 해석, 실물 검증이 완료된 것은 아니다. planning_calculation_results.json에는 이번에 실제 실행한 검산 결과만 담는다.

## 20 3D 프린팅 제작까지 확장한 목표

최종 목표를 “수정 CAD 제공”에서 “실제로 제작하고 검사할 수 있는 지그 패키지 제공”으로 확장한다. 자연어로 변경 의도를 전달하고 파라미터 변경안을 확인한 다음, 시험 적합성·구조·출력 가능성을 검토하여 부품별 출력 파일과 조립 정보를 만든다.

전체 흐름은 시험 입력 → 장비 적합 검토 → 지그 후보 생성 → 제조 방식과 재료 선택 → 출력 방향을 포함한 구조 검토 → CAD 및 메시 검사 → 프린터 배치 → 슬라이싱 → 제작 파일 확인 → 출력·후가공·조립 → 치수와 지그 성능 확인이다. 제작 조건을 바꾸면 영향을 받는 검증을 다시 실행한다.

현재 이미지의 “자연어 변경, 코드 기반 CAD, 여러 방향 미리보기, 프린팅 파일 출력” 개념을 채택한다. 특정 게시물의 미확인 Skill이나 서비스에는 의존하지 않는다. 제품의 핵심은 자연어 입력 여부와 관계없이 같은 계산·CAD·제작 검증 경로를 이용하는 것이다.

### 20.1 자동화 도구 선택과 기존 기획의 변경

| 역할 | 선택 | 구체적 사용과 범위 |
|---|---|---|
| 기본 형상 생성 | CadQuery | Python과 파라미터로 BREP 솔리드·조립을 만들고 STEP, STL, 3MF를 내보낸다 |
| 대안 CAD 엔진 | build123d | 코드 기반 CAD와 3MF를 지원하는 후보. 초기에는 동시에 구현하지 않고 동일 템플릿 벤치마크가 필요한 경우 비교한다 |
| 확인과 기존 CAD 작업 | FreeCAD | STEP 확인, 기존 FCStd 자산 수정. CadQuery STEP을 열었다고 원래 파라미터 이력이 복구되지는 않는다 |
| 표시 | 기존 Three.js 뷰어 | 회전형 3D, 정면·후면·좌·우·위·아래 6뷰와 별도 등각뷰, 단면·치수·부품 강조 |
| 메시 검사 | Trimesh | 닫힘, 면 방향, 체적, 연결 성분, 크기와 좌표 검사. 자체 교차·최소 두께 등의 전체 판정을 이것 하나로 보장하지 않는다 |
| 3MF 패키지 | CadQuery 기본 출력, 필요 시 lib3mf | 단위·부품·배치를 보존. 제조 설정과 결과 해시는 별도 JSON에도 저장 |
| 슬라이싱 | PrusaSlicer CLI | 고정 버전과 검증된 프린터·재료·출력 설정으로 배치 슬라이싱, G-code와 추정량 생성 |
| 프린터별 확장 | SlicerAdapter 인터페이스 | 다른 슬라이서를 연결할 수 있도록 입력·결과 계약을 분리. 초기에는 PrusaSlicer 하나를 검증 |

이 선택은 이번 프로그램에 대한 구현 판단이다. CadQuery가 build123d보다 언제나 우수하다는 성능 비교 결과는 아니다. 초기 채택 이유는 Python 파라메트릭 모델, 조립, STEP와 3MF 출력 경로를 한 엔진으로 구성할 수 있기 때문이다. [S6, S12, S13]

CadQuery와 build123d는 Apache 2.0 기반이며 FreeCAD, 슬라이서, CAD 커널과 그 의존성의 배포 조건은 각각 관리한다. PrusaSlicer 공식 저장소는 AGPL 계열 라이선스를 사용한다. 별도 실행 방식으로 연동해도 배포 시 라이선스 검토가 사라지는 것은 아니다. 특정 회사의 유료 CAD 좌석을 필수로 만들지 않는 것이 설계 방향이다. [S4~S6, S14]

### 20.2 CAD 원본의 단일성

기본 원본은 “CadQuery 생성 Python + parameters.json + 템플릿·커널 버전”이다. STEP, STL, model.3mf, 표시용 GLB는 파생 결과다. 원본과 파생 결과마다 같은 설계 버전과 해시를 연결한다.

기존 FCStd 자산은 cad_backend=freecad인 별도 템플릿으로 지원할 수 있다. 한 부품을 CadQuery와 FreeCAD에서 동시에 독립 수정하지 않는다. FreeCAD에서 가져온 STEP를 바꾸면 기존 CadQuery 원본의 수정으로 간주하지 않고 별도 편집 자산으로 등록하거나 템플릿을 이식한다.

### 20.3 자연어 변경 기능

예: “지지 간격 128 mm와 시편 치수는 유지하고, 이 프린터에 들어가도록 베이스를 수정해 주세요.” 시스템은 고정 조건, 변경 가능한 베이스 길이·리브·분할 접합, 제조 제약을 구조화하고 후보별 차이를 보여준다.

LLM은 변경 의도와 파라미터 후보를 제안한다. 숫자 계산, 단위 검증, 부품 정격, 출력 조건 확인은 결정적 코드가 수행한다. 자연어에서 바로 임의 코드를 생성해 장비 제어 또는 프린터 실행으로 연결하지 않는다. 새로운 템플릿 생성은 개발 단계에서 CAD·규칙 테스트를 거쳐 등록한다.

기본 폼과 치수 편집은 오프라인으로 작동한다. 자연어 기능은 선택한 로컬 모델 또는 조직이 허용한 API를 연결한 경우에만 사용한다. LLM이 없다고 전체 프로그램이 중단되지 않는다. “작게 만들어 줘”처럼 고정 조건을 침범할 수 있는 표현은 무엇을 바꾸려는지 화면에서 확인한다.

## 21 무엇을 출력하고 무엇을 조립할 것인가

초기 제조 공정은 FFF/FDM 고분자 출력으로 정한다. 모든 부품을 플라스틱으로 만드는 것을 목표로 하지 않는다. 낮은 하중의 출력 구조물과 금속 접촉부·체결부를 조합하고, 지그별로 실제 하중 경로를 계산한다. 금속 인서트가 있다고 주변 플라스틱의 파손·크리프 검사가 면제되지는 않는다.

| 시험과 기존 사례 | 출력할 후보 부품 | 초기안의 금속·상용 부품 | 제작 후 확인 |
|---|---|---|---|
| T1 인장 설계 2.5 kN | 정렬 가이드, 교체 패드의 지지 형상, 센서 브래킷 | 주 하중 경로의 그립·어댑터·핀 | 물림부 미끄러짐, 하중축, 패드 손상 |
| T3 필름 설계 50 N | 그립 인서트·몸체 후보, 교체식 접촉 지지부 | 볼트·너트·필요한 하중 분산판 | 접촉압, 반복 조임, 물림부 파손과 변형 |
| C1 발포재 설계 625 N | 리브형 받침 몸체 후보, 위치 가이드 | 평탄한 압축 접촉판·체결부 | 압축 컴플라이언스, 접촉판 휨, 유지 하중 크리프 |
| C2 고강성 시편 설계 7.5 kN | 위치 가이드·센서 브래킷 중심 | 주 하중 경로·정밀 평판 | 지그 변형과 측정 오차. 고분자 구조화는 별도 검증 |
| B1 굽힘 설계 약 166.7 N | 베이스·좌우 지지 몸체 후보·위치 스토퍼 | 롤러·압자·볼트·하중 분산 부품 | 실제 지지 간격, 처짐, 접촉부 눌림, 반복성 |
| B2 굽힘 설계 약 333.3 N | 확대 베이스·리브·가이드 몸체 후보 | 롤러·압자·필요한 금속 보강판 | 휨·체결부·출력 크기와 방향 |
| F 반복 접힘 | 클램프 하우징·반경 인서트·센서 지지부 후보 | 회전축·베어링·마모 구동부·체결부 | 백래시, 반경 유지, 마모, 반복 수명 |
| H 챔버 | 온도별 검증 재료의 허용 부품만 | 온도에 적합한 연결부와 접촉부 | 온도·시간에 따른 치수·강성·크리프 |

첫 실물 목표는 B1 굽힘 지그의 출력 베이스와 지지 몸체에 금속 롤러·압자를 조립하는 것이다. “구조물은 전부 금속, 출력물은 장식만”으로 범위를 축소하지 않는다. 출력 구조물의 강도·강성·접촉부와 체결부를 검증해 실제 하중을 부담하게 하는 것이 개발 목표다. 위 하중은 시험 예제의 요구 하중이며 출력물의 허용하중 보증값이 아니다.

부품별 manufacturing_route는 printed, purchased, machined 중 하나로 저장한다. 출력 대상만 플레이트에 배치하고 금속 롤러나 볼트까지 함께 출력하지 않는다. 부품표에는 수량, 재료, 공정, 출력 방향, 후가공, 접합 방법, 교환 가능 여부를 포함한다.

## 22 프린터와 재료 및 출력 조건

### 22.1 기준 프린터와 초기 프로파일

개발 기준은 Prusa MK4S와 PrusaSlicer 조합으로 둔다. 공개 제작 공간은 X 250 × Y 210 × Z 220 mm이다. 실제 회사 프린터의 모델을 정하기 전에도 이 기준으로 배치와 출력 파일 파이프라인을 구현할 수 있다. [S18]

초기 제조 설정은 0.4 mm 노즐, 0.2 mm 적층 높이를 개발 시작값으로 둔다. 외벽 수, 채움률·패턴, 상하단 층 수, 온도, 속도, 냉각, 서포트는 재료·부품의 검증된 출력 레시피에서 가져온다. 온도 등의 실제 값을 재료 이름만 보고 생성하지 않는다. G-code는 실물 프린터·노즐·펌웨어·필라멘트 프로파일이 확인된 뒤에만 특정 장비용 결과로 확정한다.

프린터 모델·제작 공간·노즐 직경과 재질·온도 범위·챔버 유무·재료 호환성·좌표계·시작/종료 코드·펌웨어·슬라이서 버전을 독립 입력으로 등록한다. 제작 공간은 프린터 외형 치수가 아니라 실제 사용 가능한 베드와 높이를 사용한다. 브림, 서포트, 퍼지 영역, 클립 및 금지 구역을 포함해 판단한다.

### 22.2 시편 물성과 출력 지그 물성을 분리

시편의 응력·변형률 데이터로 시험 하중을 예측한다. 출력 지그의 데이터로 그 하중을 견디는지 판단한다. 두 재료 ID를 별도로 가진다. 시험할 시편이 CFRP라고 해서 출력 지그에도 CFRP 물성을 부여하지 않는다.

상온 첫 재료 후보는 PETG로 둔다. 제조사도 홀더·클램프·기계 부품에 사용하는 재료로 소개하지만, 이 사실만으로 해당 지그의 강도나 수명을 보증하지 않는다. 실제 브랜드·등급·색상·로트, 건조 상태, 프린터, 방향, 층 높이, 외벽, 채움, 온도·속도를 묶은 출력 재료 프로파일을 검증한다. [S19]

| 재료 후보 | 개발 용도 | 승인을 위해 추가할 근거 |
|---|---|---|
| PLA | 형상·조립 시제품 | 하중 지그나 고온 사용에는 별도 검증 |
| PETG | 상온의 첫 출력 구조물·가이드 후보 | 방향별 강도·강성, 압축·체결·시간 의존 거동 |
| PA 계열·단섬유 강화 소재 | 더 높은 강성 등 요구가 있을 때 비교 | 건조·흡습, 노즐 호환, 층간 성능, 가공·출력 반복성 |
| TPU 등 연질 재료 | 시편 보호 패드 후보 | 경도·압축·마찰·영구변형과 시험 결과 영향 |

단섬유 강화 필라멘트를 연속섬유 적층재와 동일하게 취급하지 않는다. 탄소섬유 충전 재료는 내마모 노즐 등 실제 장비 조건도 확인한다. 사출재의 물성표를 출력물 허용응력으로 직접 사용하지 않는다. [S17, S20]

### 22.3 방향과 채움 조건의 구조 검증

출력물은 등방성 완전 솔리드로 단정할 수 없다. 적층 방향과 하중 방향, 외벽과 내부 채움, 구멍 주변 하중 전달, 나사 체결 압력, 층간 파괴를 고려한다. 100% 채움도 사출재와 동일 물성 또는 무결함 솔리드라는 뜻이 아니다. 제조사 설계 가이드도 출력 방향별 이방성과 금속 핀 사용을 구분한다. [S17]

초기에는 확인된 출력 레시피에 한해 유효 강성·허용값을 사용한다. 검증된 등가 모델이 없는 낮은 채움 구조는 단순 체적비 × 탄성률로 계산하지 않는다. 필요 시 실제 내부 구조를 모델링하거나 동일 레시피의 지그·쿠폰 시험에서 보정한다. 채움률을 바꾸면 재료 프로파일 일치 여부부터 다시 확인한다.

후보 방향은 서로 다른 6개 면을 베드에 놓는 방향과 필요한 축 주위 회전으로 생성한다. 순위는 구조·측정 요구 충족 여부를 먼저 적용하고, 지지물 제거·기준면 품질·베드 접착·출력 시간·재료 소모를 뒤에서 비교한다. 도구가 제공하는 안정 자세나 체적 계산만으로 최적 구조 방향이라고 표시하지 않는다.

시간을 포함한 시험에서는 크리프·응력 완화·볼트 예압 손실·온도·습도에 따른 변화가 필요하다. 반복 접힘에서는 정적 강도만으로 15만 회 사용 적합을 부여하지 않는다. 시험 하중보다 조립 볼트의 예압이 큰 경우도 검사한다.

## 23 형상에서 실제 제작 파일까지

### 23.1 CAD와 출력용 메시 검사

1. CAD에서 실제 크기, 구멍 위치, 최소 살 두께, 필렛, 공구 접근과 조립 공간을 확인한다.
2. 메시를 생성할 때 현 오차와 각도 오차를 명시하고 버전과 함께 저장한다. CAD의 곡면을 거친 삼각형으로 바꿔 접촉 반경이 달라지지 않는지 확인한다.
3. Trimesh 등의 도구로 닫힌 메시, 면 방향, 연결된 몸체 수, 체적, 단위와 bounding box를 검사한다. watertight=True가 모든 자기 교차·출력 가능성·강도를 보증하지는 않는다. [S15]
4. 자동 메시 복구로 의도한 구멍이나 틈이 사라지지 않도록 원본과 복구 후의 치수·체적을 비교한다. 구조에 영향을 주는 수정은 CAD 원본으로 돌아가 처리한다.
5. 서포트 접근, 브리징, 공정별 최소 두께, 막힌 공간, 실제 압출 경로에서 누락되는 얇은 벽을 확인한다. “45도 이상이면 항상 출력 가능” 같은 공통 상수를 사용하지 않는다.

### 23.2 파일의 역할 구분

| 산출물 | 역할 | 포함하지 않는 보장 |
|---|---|---|
| 생성 코드와 parameters.json | 재생성 가능한 설계 원본 | 원본이 있어도 제작 적합은 별도 |
| STEP | CAD·해석·가공 교환 | CadQuery의 파라미터 이력을 복원하지 않음 |
| model.3mf | 단위, 부품, 모델의 출력용 전달 | 특정 슬라이서의 온도·노즐·제조 설정을 자동 포함한다고 가정하지 않음 |
| print_project.3mf | 슬라이서에서 저장한 모델·배치·설정 | 다른 슬라이서가 모든 확장 설정을 동일하게 해석한다는 보장 없음 |
| 부품별 STL | 호환용 메시 | 단위·부품 의미·제조 설정이 충분하지 않으므로 manifest 필요 |
| G-code 또는 지원 바이너리 형식 | 지정 프린터와 프로파일의 실행 파일 | 다른 프린터에서 재사용 가능한 범용 파일이 아님 |
| BOM·조립도·검사표 | 금속 부품, 후가공, 조립·확인 항목 | 금속 조립 없이 인쇄물만으로 완성된다고 간주하지 않음 |

CadQuery의 3MF 출력과 PrusaSlicer의 설정 포함 프로젝트는 별도 단계다. PrusaSlicer는 3MF 프로젝트에 모델과 설정을 저장할 수 있으며, CLI를 통한 자동화도 공식 지원한다. 채택 버전에서 지원하는 실제 옵션과 파일 형식을 테스트하여 고정한다. 프로젝트 저장 기능이 특정 CLI에서 지원되지 않으면 GUI 저장 단계를 명시하고 설정 JSON과 모델을 함께 제공한다. [S12, S14, S16]

### 23.3 슬라이싱 검증과 인계

슬라이서가 종료 코드 0을 반환하는 것만으로 완료하지 않는다. 적용된 프린터·재료·노즐·층 높이·외벽·채움·온도 설정을 결과에서 읽어 요청값과 비교한다. 3MF에 포함된 예전 설정이 우선 적용된 경우를 잡아낸다. 실제 경로의 범위, 금지 구역, 온도 한계, 빈 경로, 경고, 서포트, 부품 누락도 확인한다.

G-code 미리보기와 해석은 채택 펌웨어·형식에서 지원하는 명령을 기준으로 한다. 압출 좌표의 절대/상대 모드와 매크로가 있으므로 단순 문자열 검색만으로 실제 운동을 전부 검증했다고 표현하지 않는다. 지원하지 않는 형식은 UNKNOWN으로 남긴다.

시간·재료량은 슬라이서 추정과 실제 제작 기록을 구분한다. 비용은 출력물·서포트·폐기 재료, 기계 시간, 후가공·조립 노동, 구입 부품, 재출력률을 분리한다. 실제 단가가 없으면 숫자를 시장가격으로 표시하지 않는다.

제품 화면은 “설계 적합”, “출력 파일 준비”, “실물 검사 완료”를 별도로 표시한다. 출력 시작은 장비가 확인된 제작 작업에서 수행한다. 초기 버전은 파일 전달까지 구현하고, 네트워크 전송·원격 출력은 프린터 인터페이스가 확인된 후속 어댑터로 둔다.

## 24 제작 관련 추가 시나리오

### P1 베드에는 들어가지만 브림까지 포함하면 넘치는 경우

기준 프린터의 X 길이는 250 mm다. 부품 길이 244 mm, 양쪽 브림 각각 6 mm, 프로젝트의 가장자리 여유 각각 3 mm라면 필요한 X 길이는 262 mm로 초과한다. 지지 간격 등 고정 조건을 유지하며 베이스 외곽·귀·배치를 수정한다. 부품 220 × 120 × 40 mm의 같은 가정에서는 238 × 138 × 40 mm 공간이 필요하다.

길이를 줄일 수 없으면 방향 변경이나 분할 조립을 검토한다. 분할은 임의 절단이 아니라 하중 경로·체결·공차·강성을 포함한 새 설계 후보다. 베드에 맞추기 위해 시험 시편이나 지지 간격을 축소하지 않는다.

### P2 형상은 같아도 출력 방향을 바꾸면 부적합해지는 경우

로직 검증용 가상 출력 재료의 허용 인장응력을 면내 20 MPa, 적층방향 8 MPa로 두고, 지배 응력을 12 MPa라고 가정한다. 해당 단축 하중에서 허용값 대비 사용률은 각각 0.6과 1.5다. 같은 외형이어도 두 번째 방향은 부적합이다.

이 숫자는 PETG나 특정 제품의 실측 물성이 아니다. 실제 복합 응력에서는 해당 방향의 인장·압축·전단과 적합한 파손 기준이 필요하다. 응력값 12 MPa도 검증용 입력이며 이번 기획에서 수행한 유한요소 해석 결과가 아니다.

### P3 출력 구멍이 맞아도 끼워맞춤 편차가 큰 경우

가상 핀 지름 8.00 ±0.01 mm, 구멍 8.25 ±0.10 mm라면 최소·최대 지름 틈새는 0.14~0.36 mm다. 요구 범위 0.10~0.30 mm에서 최대 틈새가 초과한다. 후가공 또는 부시를 적용해 구멍이 8.20 ±0.05 mm로 확인되면 0.14~0.26 mm가 된다.

이 값은 프린터의 일반 정밀도가 아니다. 방향별 구멍 쿠폰과 실제 검사에서 공차를 확인한다. 열삽입 인서트의 인발·회전 저항은 별도로 확인하고, 큰 체결력이 작용하는 부위는 관통 볼트·와셔·금속 슬리브로 예압 경로를 설계한다.

### P4 출력 시간과 비용을 줄이면서 시험 조건을 유지하는 경우

슬라이서 추정값이라는 가정으로 본체 120 g, 서포트 30 g, 폐기 10 g을 사용한다. 가상 단가는 필라멘트 30,000원/kg, 평균 전력 0.15 kW, 출력 4시간, 전력 200원/kWh, 조립 0.5시간 ×25,000원/시간, 금속 부품 6,000원이다. 직접 비용 합은 23,420원이며 기계 감가·실패율·부가세는 제외한다.

자동 개선은 불필요한 서포트, 비구조 외곽, 조립 수를 줄이는 방향에서 시작한다. 채움률을 낮추거나 층 높이를 바꾸면 해당 레시피의 강도·강성 적합성을 다시 확인한다. 슬라이싱 전후 설정을 바꾸고도 예전 구조 검증을 유지하지 않는다.

### P5 챔버 온도에서 출력 재료의 근거가 없는 경우

사용 온도 80°C인데 등록된 검증 범위가 50°C까지인 가상 재료라면 사용 범위 밖으로 판정한다. 재료의 HDT 하나를 연속 사용 온도나 장시간 하중 허용값으로 대체하지 않는다. 온도·시간·습도에 맞는 근거가 없으면 해당 부품은 검증 보류하고 다른 재료·금속화 후보를 보여준다.

### P6 반복 접힘 부품의 마모와 교체 주기

목표는 기존 F2의 15만 회다. 출력 클램프와 반경 인서트의 정적 강도가 충분해도 마모, 체결 풀림, 백래시, 반경·강성 변화와 피로 데이터를 별도로 검사한다. 초기 반복 확인만으로 15만 회 보증을 표시하지 않는다. 교체형 인서트는 고유 부품 ID와 누적 횟수·검사·교체 기록을 가진다.

추가 모듈은 manufacturing_rules, print_materials, mesh_validation, orientation_candidates, slicer_adapter, manufacturing_report, inspection_records다. 구조 해석용 모델에는 출력 좌표계와 재료 방향이 전달되어야 한다. 최종 조립 좌표와 베드 배치 좌표를 혼동하지 않는다.

추가 API는 POST /projects/{id}/manufacturing/evaluate, POST /projects/{id}/orientations, POST /projects/{id}/slice, GET /slice-jobs/{id}, POST /projects/{id}/manufacturing/export, POST /projects/{id}/inspections로 정의한다. 자연어 요청은 /change-proposals에 구조화된 제안으로 저장하고 승인된 파라미터 변경과 같은 검증 흐름을 사용한다.

입력 치수, 제조 보정 치수, 슬라이서 배율을 각각 저장한다. 구멍 치수 보정은 의도한 끼워맞춤을 실현하기 위한 제조 파라미터이며 시험의 목표 지지 간격 변경과 구분한다. 배율이 승인값과 다르면 출력 파일을 다시 검토한다.

보안·실행 경계는 기존 등록 템플릿 원칙을 유지한다. 모델이 제안한 코드나 외부 3MF의 시작 G-code를 무조건 실행하지 않고, 선택한 로컬 도구와 검증된 프로파일만 이용한다. 자연어 기능이 변경하는 대상은 형상과 제작 조건이며 시험기·프린터의 즉시 운전 명령과 분리한다.

## 26 추가 테스트와 제작 완료 조건

print_acceptance_tests.csv에 제조 과정의 필수 수용시험을 추가한다. 기존 시험 계산·장비 검사 53개도 유지한다. 기획에 필요한 수치 검산은 verify_printing_examples.py로 별도 실행하며 CAD·슬라이싱 테스트와 혼동하지 않는다.

검증 항목은 출력 방향별 허용값, 브림 포함 크기, 실제 베드 금지 구역, 단위, 메시 닫힘·부품 누락, 인서트 공차, 레시피 변경 후 판정 무효화, 슬라이서 설정 덮어쓰기, G-code 기종 일치, 지원하지 않는 명령, 프린터 미등록, 온도 범위, 반복 수명, 금속 부품 제외, 조립도·부품표, 출력물 실측이다.

소프트웨어 완료 조건: B1 수정 지그의 설계 원본·STEP·3MF·6뷰와 등각뷰·BOM·조립도·검사표가 연결되고, 확인된 프린터 프로파일로 슬라이싱한 파일의 실제 설정이 요청값과 일치해야 한다. 생성 성공과 구조·제작 검증 상태는 각각 남긴다. 6뷰는 원본 CAD에서 렌더링하며 생성형 이미지로 대체하지 않는다.

실물 완료 조건: 출력·후가공·금속부품 조립 후 지지 간격·평행도·접촉 반경·치수 공차·지그 컴플라이언스·관심 하중에서의 반복성을 확인한다. 검증된 기준 지그와 같은 시편을 시험해 하중·변위와 산포를 비교하고 허용 차이는 시험 목적과 측정 불확도에 맞춰 사전에 정한다.

개발은 기존 공통 엔진과 B1 전체 흐름에 제작 모듈을 먼저 연결하고, T/C/F 및 챔버에 확장한다. 검토용 출력, 시험 사용 적합, 실물 확인 완료를 따로 관리한다. 아직 프린터가 지정되지 않아도 CAD·메시·부품표와 프로파일 기반 사전 검증은 진행하고, 특정 기종 G-code와 실제 출력은 실물 장비 확인 후 연결한다.
