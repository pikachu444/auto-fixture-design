# 변경 기록

## 1.1 2026년 9월 28일
- 수정 지그의 3D 프린팅 제작·후가공·조립·실물 검사까지 범위 확장.
- CadQuery를 기본 CAD 엔진으로 채택. FreeCAD는 확인·편집 및 기존 FCStd 어댑터로 유지.
- 자연어 수정 제안, 6뷰·등각뷰, Trimesh 검사, 3MF 구분, PrusaSlicer 연동 정의.
- Prusa MK4S를 개발 기준 프로파일로 등록. 실물 프린터·레시피는 미확인 상태 유지.
- 시편 물성과 출력 지그 물성을 분리. 방향·채움·외벽·크리프·피로·체결 검증 추가.
- 제작 시나리오 6개와 수용시험 26개 추가. 기존 13개 시나리오·53개 수용시험 유지.
- 변경 파일은 기존 기획서와 개발 인계 패키지의 개정본으로 저장.
